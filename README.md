# RAO-AI-TRADER — site institucional

Site institucional estático para apresentar o RAO-AI-TRADER como um projeto independente de pesquisa e desenvolvimento em análise quantitativa e trading algorítmico de criptoativos.

## Publicação

O site foi preparado para GitHub Pages com publicação a partir da raiz da branch `main`. O arquivo de entrada é `index.html`; `.nojekyll` evita o processamento padrão do Jekyll.

Para habilitar: em **Settings → Pages**, selecione **Deploy from a branch**, escolha `main` e `/ (root)`. O endereço ficará disponível após a conclusão do primeiro deploy. A configuração e a disponibilidade pública dependem das permissões e do estado do repositório no GitHub.

## Desenvolvimento local

Abra `index.html` em um navegador ou sirva a raiz do repositório com qualquer servidor HTTP estático. Não há etapa de build, dependências, backend ou serviço privado obrigatório.

## Conteúdo e transparência

- Todos os componentes de arquitetura apresentados são conceituais; não são declarações de módulos operacionais.
- O painel é uma demonstração visual não operacional e não usa dados reais.
- Não são afirmadas conexão com exchanges, execução de ordens ou rentabilidade.
- O roadmap é indicativo e sujeito a mudanças.

> Este projeto tem finalidade de pesquisa e desenvolvimento. Não constitui serviço de investimento, consultoria financeira, gestão de recursos ou recomendação de compra e venda de ativos. Não há promessa de rentabilidade.
